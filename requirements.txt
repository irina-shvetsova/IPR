# Только прямые зависимости. pandas и pyarrow намеренно не указаны:
# препроцессинг работает на стандартной библиотеке csv, таблицы рисуются
# markdown-ом, поэтому тяжёлые нативные пакеты в горячий путь не попадают.
# openpyxl — исключение из этого правила по форме, не по сути: он нужен
# xlsx_parser.py для чтения сырой xlsx-выгрузки платформы (два листа,
# "Оценки" + "Комментарии"), но это чистый Python поверх zip/XML, без
# компилируемых нативных зависимостей — тот же профиль лёгкости, что и csv.
# pdfplumber (и его зависимость pdfminer.six) — для pdf_parser.py, чтения
# индивидуального PDF-отчёта 360°, который сотрудники загружают сами. Тянет
# Pillow как транзитивную зависимость — единственный по-настоящему "тяжёлый"
# пакет в этом списке, но без него из PDF таблицы не достать.
# pymorphy3 + pymorphy3-dicts-ru — тоже не лёгкие (собранный морфологический
# словарь), нужны pdf_parser.py для починки слов, разорванных пробелами
# рендером исходного PDF ("ин те ре су ешь ся" → "интересуешься"). Альтернативы
# без словаря не нашлось — эвристики по длине токена ломают короткие настоящие
# слова.
